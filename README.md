# Grocery Store Android

A real-world Android grocery store management app built for an actual store. Ships two product flavors from a single codebase.

## Features

- Two product flavors via Gradle (staff admin + customer ordering)
- MVVM architecture with per-screen ViewModels
- Dagger Hilt dependency injection
- Retrofit REST API integration
- Room local database for cart persistence
- Firebase authentication with password reset
- Inventory management admin panel
- Navigation Compose with sealed class route definitions

## Tech Stack

- Kotlin
- Jetpack Compose, Material 3
- Dagger Hilt
- Retrofit
- Room Database
- Firebase Auth, Firestore, Analytics
- Coil (image loading)
- Coroutines
